# Сюрреалізм: сторінка про митців

Навчальна адаптивна сторінка про художників-сюрреалістів. Зроблена на HTML та CSS за макетом, з готовими текстами та зображеннями. Це мій перший сайт.

## Що я зробила

- Зверстала сторінку за готовим макетом із семантичними тегами ('header', 'nav', 'section', 'article', 'footer') і логічною ієрархією заголовків.
- Винесла кольори й повторювані значення в CSS-змінні, щоб міняти їх в одному місці.
- Зробила сітку карток митців через Grid, а хедер і навігацію через Flexbox.
- Намалювала hero-блок із дверила засобами CSS.
- Адаптувала макет під планшет і мобільний за допомогою медіазапитів.
- Додала стани ':hover' та ':focus-visible', щоб сторінкою можна було користуватись з клавіатури. Перевірила це табом.
- Опублікувала сайт через GitHub Pages і вела історію змін у Git.

## Технології

HTML5, CSS3 (Grid, Flexbox, змінні, медіазапити), Git, GitHub Pages.
